# Échanges de cartes TravelTown

Petite application web familiale pour suivre les cartes TravelTown : celles qu'on a,
celles qui manquent, et les demandes ouvertes entre membres de la famille.

Application non officielle, sans lien avec l'éditeur du jeu. Sans lien d'invitation,
elle s'ouvre en mode démo avec des données fictives.
